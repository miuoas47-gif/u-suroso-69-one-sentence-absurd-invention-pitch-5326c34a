A one-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: a fridge that switches its light off and pretends to be empty after midnight, so late-night snacking means negotiating with an appliance in denial.

## Run it

```sh
python3 main.py
```

This writes the pitch (one sentence, 170 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), validates it, reads it back to confirm it matches, and exits 0. Stdlib only, no arguments, no network, deterministic.
